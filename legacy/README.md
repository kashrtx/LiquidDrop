# LiquidDrop 4.1 (Python, legacy)

This is the previous Python version, kept for reference and as a fallback.
**New users should download LiquidDrop 5 from the Releases page instead** — it's a single
file with nothing to install.

Requires Python 3.7+. Run `python liquiddrop.py` (or the `Run_LiquidDrop` launcher for your OS).
It shares the same `~/LiquidDrop` folder, token and add-ons as v5, but only run one version at a time.
